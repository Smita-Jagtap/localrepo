# Test Automation Framework

A modular Test Automation Framework for an Angular Web Application using Playwright, Python, and Pytest.

## Setup

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Install Playwright browsers**:
   ```bash
   playwright install
   ```

## Running Tests

- Run all tests:
  ```bash
  pytest
  ```

- Run sanity tests only:
  ```bash
  pytest -m sanity
  ```

- Run tests in headed mode:
  ```bash
  pytest --headed
  ```

## Reports
HTML reports are generated in the `reports/` directory.

## Logs
Logs are captured in `logs/test_logs.log`.
